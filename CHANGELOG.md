# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-07-09

### Added

- Generic TP350 / TP350S discovery by BLE local-name prefix.
- Shelly manufacturer-data decoding for temperature and humidity.
- Synthetic BTHome v2 payload generation.
- MQTT forwarding to the ioBroker Shelly adapter BLE-event topic.
- Dynamic per-MAC packet IDs and publish throttling.
- 60-second heartbeat for fresh receiver/RSSI information.
- Node.js smoke tests using the original three validated TP350S packet shapes.
- README, protocol background, credits, product/setup links, and AI handoff context.
